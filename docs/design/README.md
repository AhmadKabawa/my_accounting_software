هذه الوثائق تضبط سير العمل من فهم المهمة إلى مواصفة الشاشة ثم التنفيذ والتحقق. لا تحل محل المراجع المعتمدة؛ بل تربط بها.

## حالة المواصفات (مراجعة 2026-11-26)
الحالة من قراءة الكود على فرع التكامل `integration/catalog-scope-1` بتاريخ 2026-11-26؛ أُضيفت اختبارات CAT-07/CAT-08/CAT-10، لكن لم يُعتمد اكتمالها قبل نتيجة CI النهائية والتحقق الحي من Supabase. «منفذة» تعني وجود الكود، لا اعتماد المالك البصري.

| المواصفة | الحالة | المتبقي الأهم |
|---|---|---|
| CAT-07 الماركات | منفذة (القالب المرجعي) | B-01 رفع الشعار، التحقق الحي |
| CAT-07 الألوان | منفذة | اعتماد CL-1..CL-6، B-20..B-24 |
| CAT-07 التصنيفات | منفذة | G-1 «إضافة فرعي» من الصف، D-CAT-5، B-25 |
| CAT-07 أنواع المنتجات | منفذة جزئياً (CAT-10) | تكامل CAT-02 والتحقق الحي ونتائج CI؛ بعض معايير القبول مؤجلة |
| CAT-07 الوحدات | موجودة على فرع التكامل | اختبار CI والتحقق الحي؛ تسبق الخصائص منطقياً |
| CAT-07 الجداول الوصفية | غير منفذة | `genders` أولاً، `DatePicker` في Core للمواسم والمجموعات |
| CAT-07 أنظمة المقاسات | غير منفذة | تعتمد على `genders` |
| CAT-07 الخصائص والخيارات | موجودة على فرع التكامل | اختبار CI والتحقق الحي؛ تعتمد على الوحدات |
| CAT-01 قائمة المنتجات | غير منفذة | بعد أنواع المنتجات وCAT-02 |

ترتيب التنفيذ المعتمد (2026-11-26): أنواع المنتجات (أ) ← الوحدات ← `genders` ← أنظمة المقاسات ← الخيارات والخصائص ← بقية الجداول الوصفية ← CAT-02 ← CAT-01 ← أنواع المنتجات (ب).

## دورة العمل
تحليل ← متطلبات ← مواصفة ← قرارات مفتوحة ← تنفيذ ← تحقق.

لا يبدأ التنفيذ قبل مراجعة المواصفة واعتمادها. أي قرار غير مدعوم بمصدر يُسجل برقمه في `UI_DECISIONS_LOG.md` بعد اعتماد المالك، ولا يتحول إلى وظيفة ضمنية.
