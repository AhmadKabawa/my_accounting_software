# CAT-01 — قائمة المنتجات (الموديلات)

**الحالة:** مواصفة مراجعة، غير منفذة على الفرع `vscode` (2026-11-25).  
**المسار المقترح:** `/catalog/products`؛ لم يُثبت في route registry.  
**المراجع:** S07/S54/S55، خريطة التنقل، DATA_MODEL، V1_SCOPE، قالب الشاشة، CAT-07 المشتركة.

## الهدف والنطاق
قائمة خادمية للمنتجات (الموديلات لا المتغيرات) للعثور عليها وفتح CAT-02. لا نشر أو تعديل أو حذف من القائمة؛ الإنشاء والتعديل والنشر في تفاصيل المنتج. حالات draft/published/archived عرض فقط.

## البيانات
- products: الاسم، model_code، status، product_type_id، brand_id، created_at.
- brands، product_types، product_categories/categories (التصنيف الأساسي فقط إن ثبتت العلاقة)، product_variants (count)، product_images (الصورة الأساسية).
- لا تجلب أسعاراً أو تكاليف. أي استعلام relation/aggregate/OR عبر باركود يحتاج إثبات دعم PostgREST دون RPC/View جديدة.
- DATA_MODEL لقطة توثيق وليست اتصالاً حياً؛ راجع قاعدة البيانات قبل التنفيذ.

## الصلاحيات
القراءة حسب RLS الحالية (سيناريو S07 يذكر read-open). زر الإنشاء فقط لمن يملك catalog.manage. PermissionGate عرض UX، وRLS تفويض حقيقي. 403 حالة مستقلة.

## البحث والفلترة والفرز
- الاسم ورمز الموديل، والباركود من الخريطة يحتاج اختبار/تحقق تقنية قبل اعتماد طريقة الاستعلام.
- فلاتر النوع والماركة والحالة. لا تضف التصنيف أو اللون دون مصدر.
- escape لـ % و_، debounce/إلغاء الطلبات، وآخر طلب صالح فقط؛ تغيّر الفلتر يعيد الصفحة الأولى.
- فرز الاسم؛ تاريخ الإنشاء خيار غير معتمد حتى التحقق.
- page size يتبع AppConfig لا قيم محلية.

## العرض
هوية الصف: الصورة الأساسية (fallback)، الاسم، model_code، الحالة، الماركة، النوع، التصنيف الأساسي، وعدّ المتغيرات بحسب المساحة. هاتف: بطاقة مرتبة، مع إظهار الفلاتر في النمط الملائم. لا ID/slug/timestamps غير اللازمة.

## الحالات والتنقل
Loading skeleton، Empty مع إنشاء للمخوّل، No Results مع مسح الفلاتر، Error/retry، Permission denied. الصف يفتح CAT-02؛ العودة تحفظ query/filters/page إن كان ذلك مدعوماً بنمط التنقل الحالي.

## Responsive/RTL/Theme
تستخدم نقاط العرض كاختبارات فقط لا Breakpoints جديدة. اتبع AppDataView/ListPageTemplate وcontext.ui، التوكنز والثيم الدلالي؛ model_code/slug/barcode LTR عند الحاجة. اختبر أسماء طويلة وصورة مفقودة.

## ملاحظات تحقق مقابل vscode
لا يوجد تنفيذ products ضمن `lib/app/features/catalog` في HEAD المرجعي. هذه مواصفة لا وصف للكود. المسار والتضمينات ومكونات Core والتفاصيل غير المسندة اقتراحات؛ الكود/قاعدة البيانات/السيناريوهات المعتمدة أعلى. لا migrations أو RPC أو UI ضمن هذه المهمة.
