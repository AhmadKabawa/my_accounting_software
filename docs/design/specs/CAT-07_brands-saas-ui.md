# مواصفة UI/UX: شاشة الماركات (النمط الموحّد SaaS)

> وفق `SCREEN_UIUX_SPEC_TEMPLATE.md`. تحدّث `CAT-07_brands.md` بصرياً ولا تغيّر عقد البيانات.

## 1. معلومات الشاشة
- المسار: Catalog ▸ Brands (`BrandsScreen`، `screenId = catalog.brands`).
- القالب: `ListPageTemplate` (بطاقة واحدة: شريط أدوات + فلاتر + بيانات + تذييل).

## 2. الهدف والنتيجة
تصفّح الماركات وبحثها وفرزها وتصفيتها بثلاثة أنماط عرض، وإضافتها وتعديلها وتفعيلها وحذفها لمن يملك الصلاحية.

## 3. المرجع ومصدر الحقيقة
صورة المرجع البصري (الفكرة لا الحرف) + `CAT-07_brands.md` + `docs/audit/UI_SAAS_VERIFY.md`.

## 4. الصلاحيات
- العرض: صلاحية الكتالوج. الإضافة/التعديل/التفعيل/الحذف: `Permissions.masterData.manage` عبر `PermissionGate` (لا تظهر الأزرار بدونها).

## 5–7. السيناريوهات والبيانات
- بيانات من `BrandsRepository` (Supabase/PostgREST) مع ترقيم وفرز من الخادم.
- العرض: الاسم (+الشعار)، الوصف، عدد المنتجات، الحالة. لا عمود ID ولا Category Type ولا Export.

## 8. الإجراءات
أقصى إجراءين ظاهرين (تعديل، تفعيل/إيقاف) + قائمة «المزيد» (حذف عند `canDelete`).

## 9. المكونات
`AppStatCard` (3 عدّادات تعمل كفلتر حالة)، `FilterBar` (مبدّل العرض، بحث حبة، فرز، فلاتر، زر الإضافة في النهاية)، `AppDataView` (جدول/بطاقات/شبكة)، `AppPaginationBar`، `AppBadge` بألوان توكنات الحبات.

## 10. البحث والفلاتر والفرز
- بحث: الاسم أو slug (ilike). فلتر: الحالة فقط (الوحيد المدعوم).
- فرز من الخادم: الاسم، الحالة (`is_active`) + `name.asc` كترتيب ثانوي ثابت.
- **غير مدعوم:** فرز عدد المنتجات (يحتاج RPC/View) — فجوة خلفية موثّقة، وعموده غير قابل للفرز.

## 11. الجدول
أنماط: Table | Cards | Grid. الافتراضي: Table (Cards على الهاتف). الاختيار يُحفظ لكل شاشة. إذا ضاق العرض عن عمودين يسقط الجدول إلى Cards تلقائياً ما لم يُختر نمط صراحةً. الهاتف: «تحميل المزيد» عند توفر `onLoadMore`، وإلا ترقيم.

## 13–14. الحالات
تحميل (هياكل تتبع النمط) · فارغ (بلا فلاتر: دعوة للإضافة؛ مع فلاتر: لا نتائج) · خطأ (لافتة + إعادة المحاولة تستبدل البيانات) · خطأ أثناء التحديث (لافتة مع إبقاء البيانات) · تحديث.

## 15–17. Responsive / RTL / Light-Dark
360/600/900/1200/1366 × Light/Dark × RTL/LTR، بلا ألوان أو أبعاد حرفية (توكنات Core فقط).

## 18. مكونات Core
جديدة/معدّلة: `AppDataView`, `AppStatCard`, `FilterBar`, `ListPageTemplate`, `AppSaasColors`.

## 19. API
لا تغيير في المخطط أو العقد: يُضاف فقط `order` من قائمة بيضاء (`name`, `is_active`) في الطلب القائم.

## 20. قرارات غير محسومة
- فرز عدد المنتجات يحتاج قراراً خلفياً (View/RPC).
- هل تُضاف أعمدة فرز أخرى (`created_at`)؟ يتطلب إظهارها في الكيان.

## 21. الاختبار
اختبارات الاستعلام (القائمة البيضاء)، شريط الإحصاءات، شريط الفلاتر (فرز)، قسم الجدول، الشاشة (إجراءات ومصفوفة responsive). **لم يُشغَّل أي اختبار** (لا Flutter في بيئة العمل).
