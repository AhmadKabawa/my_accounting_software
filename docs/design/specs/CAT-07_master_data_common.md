# CAT-07 — القواعد المشتركة لشاشات البيانات الأساسية (باستثناء الماركات والألوان)

**الحالة:** توجيه مقترح؛ ليس عقداً نهائياً.  
**المراجع:** CAT-07_brands.md (طيار)، CAT-07_colors.md (مواصفة قائمة)، SCREEN_UIUX_SPEC_TEMPLATE، V1_SCOPE، DATA_MODEL، S46–S53.

## 1. النطاق والترتيب
الترتيب التشغيلي يتبع V1_SCOPE وقرارات المستخدم، وليس هذا الملف. الترتيب المقترح في الملفات التفصيلية لا يفرض جدولة التنفيذ. الأنواع المطلوبة لإنشاء المنتجات قد تكون اعتماداً مبكراً، لكن لا تُعدّل خطة الإصدار هنا.

## 2. المبادئ المشتركة
- القراءة بحسب RLS، والكتابة وفق masterdata.manage ما لم يحدد مصدر آخر.
- إظهار حالة active/inactive، وإخفاء inactive من اختيارات الإنشاء الجديدة فقط وفق قواعد الخادم؛ لا تمنع العرض التاريخي.
- حذف مرجع مرتبط غير آمن؛ لا تعرض حذفاً إلا إذا أكد مصدر البيانات أنه ممكن. الإيقاف هو البديل الآمن عندما يفرضه الاستخدام.
- البحث/الفرز/الترقيم يعتمد AppConfig وCore، لا قيم محلية.
- الأخطاء المترجمة، رفض الصلاحية، Loading/Empty/No Results/Error.
- لا تكرر CRUD engine أو widgets. اتبع ListPageTemplate، ListToolbarConfig، AppDataView، AppFormDialog/CrudEditorDialog عند ملاءمتها، PermissionGate وAppValidator بعد التحقق من التواقيع.
- Responsive على 360/600/900/1200 كاختبارات، لا Breakpoints مستقلة. RTL/LTR وLight/Dark من tokens/semantic colors.
- أي رابط/route أو widget غير موجود يبقى مقترحاً ولا يوهم بوجود التنفيذ.
- كل مواصفة entity تتبع SCREEN_UIUX_SPEC_TEMPLATE؛ أي قرار غير مدعوم يوسم مفتوحاً أو اقتراحاً.

## 3. مصادر الحقيقة
الكود الفعلي أولاً؛ قاعدة البيانات/RLS/schema ثاني مرجع فعلي؛ سيناريوهات/قرارات معتمدة؛ مواصفات الشاشة؛ ثم المقترحات. عند التعارض تُراجع الوثائق القديمة ويُسجل القرار، لا يُخترع سلوك.

## 4. التحقق مقابل vscode
لا توجد features catalog لهذه الكيانات (عدا brands/colors) في شجرة الكود المرجعية. لا يتجاوز هذا الملف نطاق الوثائق، ولا يعدّل brands/colors. DATA_MODEL لقطة وليس قراءة حية. لا migrations أو routes.
