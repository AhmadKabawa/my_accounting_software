# CAT-07 — الخصائص ومجموعات الخيارات

**الحالة:** مواصفة مقترحة غير منفذة. المسارات المقترحة: `/catalog/attributes` و`/catalog/option-sets`.  
**المراجع:** S53، DATA_MODEL، ERP27/28.

## النطاق
تعريف مجموعة الخيارات وخياراتها، وتعريف الخصائص typed. الربط بين الخصائص ونوع المنتج في شاشة نوع المنتج، وقيم الخصائص في CAT-02، خارج نطاق شاشة التعريف.

## البيانات والقيود
أنواع الخصائص (text/number/boolean/date/json/option وفق المصدر) والربط مع option set فقط للنوع option يجب أن تطابق schema والقيود الفعلية. لا تفترض وجود بيانات إلزامية تمنع نشر المنتج إن كانت جداول الربط غير مستخدمة أو فارغة. لا تضف أنواع/قيود من عندك.

## شاشات
- مجموعات الخيارات: list/editor للمجموعة وخياراتها وترتيبها وتحديد ما يسمح به schema.
- الخصائص: list/editor لاسم/رمز/نوع/وحدة أو مجموعة خيارات عند انطباق النوع، حسب schema.
- البحث، حالة/ترقيم، وأفعال CRUD/تعطيل مع فحص الارتباطات.

## حالات/تصميم
Loading/Empty/No Results/Error/Permission Denied، responsive وRTL/light-dark عبر القوالب الحالية.

## مراجعة
لا تنفيذ لهذه الميزات على vscode. أسماء الحقول والقيود ومساراتها المقترحة ليست عقود API؛ راجع قاعدة البيانات الفعلية والسيناريو قبل تنفيذ. لا migrations.
