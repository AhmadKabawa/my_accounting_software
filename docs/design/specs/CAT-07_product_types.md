## 0. الملخص

نوع المنتج (حذاء، قميص...) هو **جذر إعدادات المنتج**: يحدد مجموعات المقاسات الافتراضية (S48) والخصائص والإلزامي قبل النشر (S53) وتعليمات العناية الإلزامية (S51). لذلك تُقسَّم المواصفة إلى **مرحلتين**: **المرحلة أ** قائمة ونموذج (اسم، رمز، وصف، ترتيب) — شرط لإنشاء أي منتج لأن `products.product_type_id` NOT NULL؛ **المرحلة ب** صفحة تفاصيل النوع بتبويبات الربط، وتعتمد على مواصفات المقاسات والخصائص.

## 1. معلومات الشاشة
- **لماذا وحدة مفهومة؟** كيان مستقل له سلوك ربط خاص (S49: «نوع المنتج يرتبط بالمقاسات والخصائص»).
- **لماذا مرحلتان؟** المرحلة أ لا تعتمد على أي شاشة أخرى؛ المرحلة ب تحتاج مجموعات المقاسات والخصائص موجودة، ولا تُعرض تبويبات بلا تنفيذ (D-02).

## 2. الهدف والنتيجة
- **أ:** مخوَّل يعرّف نوعاً (اسم ورمز) فيظهر في إنشاء المنتج.
- **ب:** يربط النوع بمجموعة مقاسات افتراضية (S48) وبخصائصه ومجموعات خياراته وتعليمات العناية (S53 وS51).
- **اكتمال المهمة:** النوع يظهر في قائمة النوع بنموذج المنتج؛ منتج جديد من النوع يرث مقاساته (S48-AC1).

## 3. المرجع ومصدر الحقيقة
| القرار/المعلومة | المصدر |
|---|---|
| حقول النوع | S49 + DATA_MODEL: `product_types` |
| `code` فريد، `name` غير فريد | DATA_MODEL: `uq (code)` |
| ربط المقاسات | S48 + `product_type_size_groups` |
| ربط الخصائص | S53 + `product_type_attributes`, `product_type_option_sets` |
| عناية إلزامية | S51 + `product_type_care_instructions.is_required` |
| ما لم يرد | هل يجوز تغيير نوع منتج بعد إنشائه · أثر تغيير إلزامية خاصية على منتجات منشورة · حذف نوع عليه ربط |

## 4. المستخدمون والصلاحيات
كما في المشتركة C2. جداول الربط كلها `masterdata.manage` للكتابة وقراءتها مفتوحة.

## 5. السيناريوهات
**S49 الخطوة 4 (المرحلة أ):** «نوع منتج جديد» ← الاسم، الرمز، الوصف ← حفظ.
**S49 الخطوة 5 + S48 (المرحلة ب):** فتح النوع ← تبويب «مجموعات المقاسات» ← ربط مجموعة (الجنس، افتراضية، الترتيب) ← تبويب «الخصائص» ← ربط خاصية (إلزامية، ترتيب) ← تبويب «مجموعات الخيارات» ← تبويب «العناية» (إلزامية/اختيارية).
- **أخطاء:** رمز مكرر · مجموعتان افتراضيتان لنوع وجنس (واجهة: «يوجد افتراضي واحد لكل نوع وجنس»).
- **ملاحظة:** القاعدة لا تفرض «افتراضي واحد» لنوع وجنس (لا فهرس جزئي على `product_type_size_groups.is_default`؛ يوجد فقط `ux_pt_size_groups` لفرادة التركيبة). الإلزام واجب في الواجهة.

## 6. البيانات
| الجدول | الحقول | العلاقة |
|---|---|---|
| `product_types` | `id`, `name` v(150)!, `code` v(50)! فريد, `description`, `is_active`, `sort_order` | — |
| `products` | `product_type_id` **NOT NULL** | FK بلا cascade → نوع مستخدم لا يُحذف |
| `product_type_size_groups` | `product_type_id`, `size_group_id`, `gender_id`, `is_default`, `sort_order` | `ux_pt_size_groups (type, group, gender) NULLS NOT DISTINCT` |
| `product_type_attributes` | `product_type_id`, `attribute_id`, `is_required`, `sort_order` | PK مركّب |
| `product_type_option_sets` | `product_type_id`, `option_set_id`, `is_required`, `sort_order` | PK مركّب |
| `product_type_care_instructions` | `product_type_id`, `care_instruction_id`, `is_required`, `sort_order` | PK مركّب |
| `price_rules`, `discount_targets` | `product_type_id` / (`target_type='product_type'`) | الأولى FK، الثانية بلا FK |
- **الاستخدام:** `products(count)` بالعلاقة المؤكدة.
- **جداول الربط بلا `ON DELETE CASCADE` من جهة النوع:** حذف نوع له ربط يفشل بـ 23503 (أو يتطلب حذف الربط أولاً).
- **حالة البيانات (2026-11-16):** `attributes` و`product_type_attributes` فارغان.

## 7. المعلومات المعروضة (قائمة المرحلة أ)
| العنصر | الأولوية | المصدر |
|---|---|---|
| الاسم + الرمز (`code` بخط ثابت العرض) | أساسي | `name`, `code` |
| الحالة | أساسي | `is_active` |
| عدد المنتجات | ثانوي | `products(count)` |
| الوصف | ثانوي | `description` |
| ملخص الربط (مجموعات مقاسات، خصائص، عدد الإلزامي) | **المرحلة ب فقط** | عدّادات الجداول الفرعية |

## 8. الإجراءات
كما في المشتركة C5، مع:
- **الحذف:** لا يظهر إن وُجدت منتجات **أو** روابط (مقاسات/خصائص/عناية)؛ الإيقاف هو البديل.
- **إيقاف نوع له منتجات:** يُخرجه من اختيار المنتج الجديد فقط (S49 «تعطيل بدل حذف ما استُخدم»).
- المرحلة ب: «إضافة ربط» و«إزالة ربط» داخل كل تبويب؛ إزالة الربط حذف صف ربط (لا يمس المنتجات القائمة — S48: «تغيير مجموعة النوع لا يمس متغيرات قائمة»).

## 9. المكوّنات
كما في المشتركة C8. للمرحلة ب: **`Tabs` غير موجود في Core (تحقق 2026-11-26)** فلا تُبنى تبويبات؛ البديل في §23 P-1، `SearchableDropdown` لاختيار المجموعة/الخاصية، `AppBadge` لـ«افتراضية» و«إلزامية».

## 10. البحث والفلاتر والفرز
- **البحث:** `name` و`code`.
- **فلتر الحالة:** كما في المشتركة. لا فلاتر أخرى: لا حقل موثق يستحق.
- **الفرز:** `sort_order` ثم `name`.

## 11. القائمة
1. الاسم + الرمز (هوية).
2. الحالة.
3. عدد المنتجات (ثانوي).
4. الإجراءات: تعديل + المزيد.
- المرحلة ب: النقر على الصف يفتح تفاصيل النوع (صفحة كاملة بأقسام مرتبة، انظر §23 P-1)؛ في المرحلة أ يفتح التعديل.

## 12. النموذج (المرحلة أ)
| الحقل | التحقق |
|---|---|
| الاسم | إلزامي، ≤ 150 |
| الرمز | إلزامي، ≤ 50، فريد (409/23505 رسالة واحدة) |
| الوصف | اختياري |
| الترتيب | اختياري، عدد صحيح |
- **صُحّح:** مفتاح «نشط» في المحرر (D2: يُرسل عند الإنشاء، وفي PATCH عند التغيّر فقط) بدل «لا حقل حالة». **الرمز:** يُعامل كمعرّف ثابت؛ تعديله بعد الاستخدام قرار D-PT-2.

## 13–18. الحالات وResponsive وRTL وCore
كما في المشتركة. المرحلة ب: تبويب بلا ربط → `AppEmptyState` («لا مجموعة مقاسات لهذا النوع» كنص S48، «لا خصائص لهذا النوع» كنص S53).

## 19. API
| العملية | Endpoint |
|---|---|
| GET (أ) | `/rest/v1/product_types?select=id,name,code,description,is_active,sort_order,products(count)&order=sort_order.asc,name.asc` |
| POST/PATCH/DELETE | كما في المشتركة C9 |

### 23.3 المرحلة أ — عقد التنفيذ المختصر
- **الأعمدة:** الاسم+الرمز (هوية، الرمز LTR)، الوصف (ثانوي)، عدد المنتجات (`products(count)`، `—` عند الجهل)، الحالة، الإجراءات.
- **البحث/الفرز:** خادمي: `name`/`code` بـ`ilike` مع escaping؛ فرز `sort_order` ثم `name` ثم `id`.
- **الإحصاءات:** الكل/نشطة/موقوفة.
- **الحذف:** يظهر فقط عند `productCount == 0` **و**عدم وجود روابط؛ المرحلة أ لا تقرأ الروابط، لذا **يعتمد على FK**: 23503 → `ProductTypeInUseFailure` برسالة «أوقِف بدلاً من الحذف». لا يُفترض أن عدم وجود روابط معروف في المرحلة أ.
- **النموذج:** الاسم، الرمز (فريد؛ 23505 → خطأ على الحقل)، الوصف، الترتيب، مفتاح الحالة. النسخ: اسم/رمز جديدان.
- **اختبارات:** كاملة بنمط التصنيفات (Model، Repository، Cubit، شاشة 360/1200×اتجاهين، قراءة فقط).
