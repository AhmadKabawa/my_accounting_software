# CAT-07 — أنظمة المقاسات

**الحالة:** مواصفة مقترحة غير منفذة. المسار المقترح: `/catalog/size-systems`.  
**المراجع:** S47/S48/S08 وDATA_MODEL.

## البنية
إدارة مرجع المقاسات بمستويات النظام ومجموعات المقاسات والقيم والنطاقات (إن كانت الجداول والحقول قائمة). النظام ← المجموعة ← المقاسات؛ روابط النوع/المنتج لا تُدار هنا، بل في شاشة نوع المنتج أو CAT-02 وفق السيناريو.

## المسؤوليات
إنشاء وتعديل وتفعيل/تعطيل البيانات المرجعية؛ إدارة المجموعة ومقاساتها في سياق النظام لتجنب orphan records. قبل حذف أي عنصر تحقق من علاقاته. الجنس/الفئة أو الترتيب والنطاقات لا تُفرض إلا وفق مصدر البيانات.

## عرض/بحث
فهرس الأنظمة، فتح نظام لإدارة مجموعاته، وتحرير المقاسات في المجموعة. البحث والفرز/الترقيم حسب القالب المشترك؛ لا invent bulk operations.

## Responsive/حالات
Loading، Empty، No Results، Error، Permission denied. شجرة/قائمة متدرجة تتحول إلى تخطيط ملائم للشاشات الضيقة عبر القوالب الحالية؛ RTL/LTR والثيم الدلالي.

## مراجعة مقابل vscode
لا تنفيذ لهذه الجداول/الشاشة ضمن catalog. المسارات والواجهات غير قائمة. تحقق من DATA_MODEL والقاعدة الحية والقيود والعلاقات قبل اعتماد هذا الوصف للتنفيذ. لا migrations.
