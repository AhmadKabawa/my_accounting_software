# سجل القرارات والنقاط المفتوحة

**المرجع الوحيد** للنقاط المفتوحة والمؤجلة. كانت موزعة على أربعة أماكن (خريطة الشاشات §11، وخريطة الاعتماديات §13، و`DATA_MODEL §13`، و`SUPABASE_API_INTEGRATION §11`)؛ تبقى تلك الأقسام للتفصيل التاريخي وتشير إلى هنا، ولا يُضاف بند جديد إلا في هذا الملف.

آخر مراجعة: 2026-11-16 (مراجعة ما قبل المرحلة الأولى). القرارات المعتمدة بأرقامها في `docs/product/scenarios/A4_decisions_log.md`.

**الحالات:** `محسوم` · `v2` (مؤجل صراحةً، يبقى موثقاً) · `عند الشاشة` (ملاحظة تُحسم عند الوصول إلى شاشتها) · `مفتوح` (يحتاج فعلاً أو جواباً).

## 3. ملاحظات تُحسم عند الوصول إلى شاشتها

كانت اقتراحات لحظية أو بنوداً لا تعطّل v1؛ لا تُحسم الآن.

| # | الملاحظة | الشاشة / المرحلة |
|---|---|---|
| N-01 | Realtime للبث الفوري: غير مفعّل ولا يُفترض | المخزون وPOS (بعد v1) |
| N-02 | التحقق الآلي من OpenAPI مقابل الواجهات | عند استقرار الدوال |
| N-03 | إعادة التحقق من الجلسة المخزَّنة (SECURITY_DECISIONS) | AUTH-01، مع ADR الصلاحيات |
| N-04 | `payments` بلا `payment_number` (DM §13/1) | FIN-01، FIN-06 |
| N-05 | رؤية السلف بالفروع مقابل `apply_advance` من أي فرع (DM §13/2) | FIN-06 |
| N-06 | `v_open_documents` لا تخصم المرتجعات (DM §13/6) | ACC-04، FIN-06 |
| N-07 | نص ERP01 في القاعدة لا يذكر REVERSED؛ نصنا العربي ينسخه | أول شاشة تعرض مستنداً معكوساً |
| N-08 | ADM-03: هل يطّلع AUDITOR؟ (تعارض §4.2 و§5) | ADM-03 |
| N-09 | قيم `reference_type` غير المؤكدة (§11 بند 10) | قبل بناء الروابط بين المستندات |
| N-10 | الأخطاء ذات المتغيرات (اسم الصنف، النسبة، الرصيد المتاح) وملحق «و» | أول شاشة تحتاجها؛ `ApiException.details` محفوظ |
| N-11 | `v_variant_list_prices`: لا سجل ولا سعر مستقبلي (S74) | CAT-03 |
| N-12 | نصف قطر tablet/desktop في التصميم إن لم يُعتمد | عند أول مكوّن يحتاجه |
| N-13 | شكل ردود الدوال غير الموثقة (DTOs) | عند أول استعمال لكل دالة |
| N-14 | `Money` والتقريب: اختبار مقابل `currencies` الفعلية | CAT-03 |
